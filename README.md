# Haretna

Haretna is a community idea for helping neighborhoods report small problems and organize people to fix them.

It lets residents share issues like trash, broken sidewalks, or neglected public spaces, then turn those issues into simple volunteer action. 

the goal is to make community help feel visible, local, and easy to join.

this repo is mainly a frontend demo of that idea. 

It is meant to show the concept clearly, not to be a full production platform yet.

the backend folder is included, but not linked to the frontend yet
